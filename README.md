## Research & Academic Projects
- **FinRAG/FinSights: Production-Grade Financial Intelligence System** — Hybrid dual-path architecture combining structured queries (DuckDB/SQL dimension tables) with semantic retrieval. Processes 72M→1M sentences via stratified sampling with temporal weighting across regulatory eras. [FinSights](https://github.com/mjsushanth/FinSights/blob/revival/main/README.md)

[See Report here.](https://github.com/mjsushanth/CLIP-Conditioned-Diffusion-T2Pose-Generation/blob/main/RESEARCH_README.md), [See Design here.](https://github.com/mjsushanth/CLIP-Conditioned-Diffusion-T2Pose-Generation/blob/main/DESIGN_README.md)
